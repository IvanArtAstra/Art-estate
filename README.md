# Estate Art — сайт недвижимости на Пхукете

Премиальный лендинг с кинематографичным скролл-облётом Пхукета (видео скрабится скроллом, Apple-style).

## Как запустить локально

```bash
cd "Art Estate"
python3 -m http.server 8123
```
Откройте в браузере: **http://localhost:8123**

> Важно: открывать именно через сервер (а не двойным кликом по `index.html`),
> иначе браузер может не отдать видео для покадровой перемотки.

## Видео-облёт (hero)

22-секундный кинематографичный облёт, который скрабится скроллом: камера летит
над Пхукетом → подлетает к вилле → входит в стеклянные двери → влетает в интерьер
с видом на океан. Закодирован all-intra (каждый кадр ключевой) для идеально
плавной перемотки. Поверх сменяются 3 текстовых слоя синхронно с актами.

Сгенерировано в Higgsfield (кадры — `nano_banana_pro`, видео — `seedance_2.0`
с переходами по start/end-кадрам) и склеено через `ffmpeg`.

## Каталог из fazwaz.ru

Каталог рендерится из `data/catalog.json`. Обновить реальными объектами:

```bash
python3 scraper/scrape_fazwaz.py --pages 1 --limit 12
```
Затем обновите страницу. Подробности и параметры — в `scraper/README.md`.
⚠️ См. правовое замечание там: фото/описания принадлежат fazwaz и их партнёрам.

## Функции каталога (как у fazwaz, в нашем дизайне)

- **Поиск и фильтры** над каталогом: текстовый поиск (название/район), тип,
  спальни, диапазон цены, сортировка (цена / площадь / $ за м²), счётчик
  результатов. Всё мгновенно, на стороне браузера — без бэкенда.
- **Сравнение**: кнопка «Сравнить» на карточке → плавающая панель (до 4 объектов)
  → модалка со сравнительной таблицей (цена, $/м², спальни, площадь, пляж,
  аренда, доходность).
- **Карточка объекта** (по клику): фото, характеристики, описание, кнопки
  WhatsApp/Telegram с подстановкой названия объекта, и два калькулятора:
  - **Кредитный** — стоимость, первоначальный взнос %, ставка %, срок →
    платёж/мес, сумма кредита, переплата (аннуитет).
  - **Доходности** — стоимость, аренда/мес, загрузка % → доход/год, доходность,
    окупаемость. Аренда подставляется из объявления либо оценивается (~6%).

Курс KZT→USD и допущения калькуляторов (ставка/срок/загрузка) — дефолтные,
правятся: курс в `scraper/scrape_fazwaz.py` (`RATES_TO_USD`), дефолты
калькуляторов — в `js/script.js` (значения `value=...` у инпутов).

## Функции «как у fazwaz» (вторая волна)

- **Поисковая панель** под героем: строка поиска + быстрые чипсы районов → ведёт в каталог.
- **Бейджи на карточках**: «X% доходность от аренды» (считается) и «−X%» скидка
  (по `firstPrice` из объявления, показывается зачёркнутая старая цена).
- **Избранное (♥)** на карточках — хранится в браузере (localStorage), фильтр
  «Избранное» в тулбаре.
- **Фильтр по району** и кнопка **«Показать ещё»** (пагинация по 9).
- **Секция «Районы Пхукета»** — карточки районов с числом объектов → клик фильтрует каталог.
- **Секция «Гибкие способы покупки»** — аренда с выкупом, рассрочка, поэтапная
  оплата + кнопка, открывающая калькуляторы.
- **Мини-карта (Leaflet + OpenStreetMap)** в карточке объекта по координатам из
  данных (`lat`/`lng`). Требует интернет для тайлов карты.

## Функции «как у fazwaz» (третья волна)

- **Боковое меню (drawer)** по кнопке ☰ — навигация, переключатель валюты,
  контакты, кнопки WhatsApp/Telegram, «Оставить заявку».
- **Переключатель валюты USD / ₽ / ฿** — мгновенно пересчитывает все цены
  (карточки, скидки, $/м², сравнение, срочная продажа, карта). Выбор сохраняется
  в браузере. Курсы — в `js/script.js`, объект `CURRENCIES` (правятся под актуальные).
  Калькуляторы в карточке считают в USD (помечено «$»).
- **Блок «Почему с нами»** с зацикленным видео-облётом и тремя преимуществами.
- **Секция «Срочная продажа»** — объекты со скидкой (старая/новая цена, «−X%»).
- **Секция «Объекты на карте»** — все объекты каталога маркерами на карте Пхукета
  (Leaflet + OpenStreetMap); клик по маркеру → цена и кнопка «Подробнее».

## Страницы объектов (SEO, многостраничность)

У каждого объекта — отдельная человекочитаемая страница с уникальными мета-тегами:
```
/object/<slug>-u<id>/        напр. /object/nai-harn-beach-condominium-u5346015/
```
Что на странице: `<title>`/description/canonical под объект, OpenGraph + Twitter,
**schema.org** разметка (Product + Offer + BreadcrumbList), хлебные крошки, фото,
характеристики, цена в $/₽/฿, описание, кредитный калькулятор и калькулятор
доходности, карта. Плюс генерируется **`sitemap.xml`** со всеми URL.

Генерация (после парсера):
```bash
python3 scraper/build_pages.py
```
Скрипт читает `data/catalog.json`, создаёт `object/<slug>/index.html` для каждого
объекта, дописывает в каталог поля `slug`/`url` (карточки сайта ссылаются на эти
страницы) и пишет `sitemap.xml`. `update-catalog.sh` уже вызывает его автоматически.

> Для индексации добавьте сайт и `sitemap.xml` в Google Search Console / Яндекс.Вебмастер.

## GIF-баннеры «Переезд во Вьетнам / Таиланд»

Секция `#relocation` на главной. Баннеры собираются скриптом, а не руками:

```bash
python3 tools/make_banners.py
```

На каждую страну получается по четыре файла в `assets/banners/`:

| файл | размер | где нужен |
|---|---|---|
| `relocation-<страна>.gif` | 1200×630, ~350 КБ | десктоп, Telegram, OG-превью |
| `relocation-<страна>-p.gif` | 1000×1250, ~110 КБ | телефон (подставляется через `<picture>`) и вертикальные ленты |
| `…-p.webp` / `….webp` | постеры | `prefers-reduced-motion: reduce` |
| `…-p.jpg` / `….jpg` | постеры | площадки без webp |

Что менять в `tools/make_banners.py`:

- тексты и города — в `CONFIGS` (`line1`, `line2`, `sub`, `footer`);
- координаты блоков — в `WIDE` и `PORTRAIT`;
- рисунок справа/сверху — функции `motif_vietnam` и `motif_thailand`.

Анимация намеренно живёт в одной горизонтальной полосе вокруг кнопки: GIF пишет
дельта-кадры, поэтому файл весит сотни килобайт, а не мегабайты. Если добавите
движение в другой части кадра — вес вырастет в разы.

Шрифты берутся системные (Baskerville и Avenir Next), так что скрипт рассчитан
на macOS. На другой ОС поправьте пути `SERIF` и `SANS` вверху файла.

## Вьетнам: Дананг и Нячанг

У каждого объекта в `data/catalog.json` есть `country` (`th` / `vn`), `countryName`
и `city`. На них завязаны переключатель стран с флагами, фильтр по городу, карта
и SEO-страницы.

Собрать или обновить объекты:

```bash
python3 scraper/scrape_fazwaz.py --regions danang,nhatrang --merge --limit 12 --pages 6
```

- `--regions` — `phuket`, `danang`, `nhatrang` через запятую (пути категорий заданы
  в словаре `REGIONS` вверху скрипта);
- `--merge` — объекты городов, которые сейчас не собираются, останутся на месте;
  без флага каталог перезаписывается целиком;
- `--no-quality-filter` — отключить отсев.

**Фильтр качества.** В категориях «продажа» у источника попадается мусор: объявления
об аренде, реклама агентов капсом на вьетнамском и битые цены (в поле цены оказывается
месячная аренда — отсюда «$846 за 50 м²»). Функция `card_quality()` отсеивает такие
карточки до захода на страницу объекта: по эмодзи и капсу в названии, по словам
об аренде, по цене ниже $25 000 и по цене за м² вне коридора $400–25 000. На практике
отсеивается больше половины выдачи — это нормально.

**Координаты.** С 2026 года источник не отдаёт `lat`/`lng` ни в листинге, ни на
странице объекта. Парсер берёт их со страницы ЖК, куда ведёт ссылка с карточки,
а если ЖК не найден — геокодирует адрес через Nominatim (OSM) с паузой в секунду,
как требуют их правила.

**Страницы городов.** Во Вьетнаме в адресе стоит квартал (Hoa Hai, Tan Lap), поэтому
`build_pages.py` группирует Вьетнам по городу, а Таиланд по району — иначе выходил
десяток страниц с одним объектом на каждой.

## Партнёры, каналы и закрытые контакты

`data/channels.json` — 21 компания (агентства и застройщики Дананга и Нячанга)
и 10 живых Telegram-сообществ. Каждый контакт подтверждён загрузкой официальной
страницы компании; у записей проставлено поле `verifiedAt`.

Контакты вынесены в отдельный `data/contacts.json`, который подгружается только
после регистрации в модалке на сайте. Регистрация бесплатная, хранится
в `localStorage` под ключом `ae_reg`.

> **Это сбор заявок, а не защита.** Контакты не попадают в разметку страницы
> и не индексируются поисковиками, но `data/contacts.json` доступен по прямой
> ссылке любому, кто её наберёт. Чтобы закрыть контакты по-настоящему, нужен
> бэкенд, отдающий их по токену после регистрации. Сейчас бэкенда у сайта нет —
> это статика на GitHub Pages.

Сообщества показываются без замка: гейт на публичный `t.me`-канал смысла не имеет.

Мессенджер-контакты устаревают быстрее телефонов — раз в полгода стоит пройтись
по `verifiedAt` и перепроверить.

## Комиссии и условия работы с партнёрами

Внутренняя записка для переговоров: `docs/vietnam-commissions.md`, структурированные
данные — `data/commissions.json` (97 записей, у каждой ссылка и дословная цитата).

> Оба файла **намеренно не в репозитории**: он публичный, а в записке наши
> переговорные позиции, якоря для торга и список вопросов к контрагентам.
> Они лежат на диске и перечислены в `.gitignore`. Если нужен общий доступ —
> заведите приватный репозиторий или положите в облако с ограниченным доступом.

Коротко, что выяснилось:

- Ставки комиссий во Вьетнаме **законом не установлены** — всё договор. «Рыночная
  норма» ни к чему не обязывает, но служит якорем в торге.
- Вторичка: продавец платит агенту **1–3%** (устойчиво по четырём независимым
  источникам), сверху 10% НДС на услуги агента.
- Новостройки: застройщик платит агентству **2–3%** базово, **3–5%** эксклюзивному
  генеральному агенту. Весь бюджет продаж застройщика — 6–8% выручки, это потолок
  того, из чего он может делиться.
- Премиум (виллы, пентхаусы) даёт ставку **ниже** — 0,8–1,5%. Контринтуитивно, но
  подтверждено: по дорогим объектам торгуются не за процент, а за фикс-бонус.
- Аренда: 100% месячной аренды при договоре на год, 150–200% при 24+ месяцах.
- **Ни одно из 14 проверенных агентств Дананга и Нячанга не публикует партнёрских
  условий**, и ни один застройщик не публикует агентскую ставку — она живёт
  в закрытом документе `chính sách bán hàng` под конкретный проект. Договор
  придётся писать с нуля.
- Лучший найденный публичный ориентир по первичке — **1,5–2,5% от цены объекта**
  с выплатой за 7 рабочих дней (Newway Realty, F1-дистрибьютор Vinhomes и Sun Group).

Правовая рамка: по Закону 29/2023/QH15 (в силе с 01.08.2024) брокерить вьетнамский
объект без сертификата и вьетнамского юрлица нельзя, штраф 40–60 млн VND. А вот
получать от лицензированного вьетнамского агентства плату за приведённого клиента
можно — при правильном оформлении. Детали и список вопросов для первого контакта
с агентством — в записке.

## Правовое замечание по источнику каталога

Каталог (и Пхукет, и Вьетнам) собирается с fazwaz.ru. Проверка показала:
`robots.txt` площадки закрывает только `/api/` и `/graphql`, то есть страницы
листингов обходить он не запрещает, **но юридическая нотиция оператора
(LIFULL Connect) прямо запрещает extract и compile контента**. Технически сбор
возможен, по условиям использования — нет. Это касается всей группы: `fazwaz.ru`,
`fazwaz.vn`, `asia.villas`, `dotproperty.com.vn`.

Решение за владельцем сайта. Варианты:

1. договориться с оператором и работать по соглашению;
2. перевести каталог на порталы, где сбор не запрещён — по проверке подходят
   **mogi.vn** (Дананг 10 417 объектов, Кханьхоа 2 124) и **homedy.com**
   (5 658 и 1 544): `robots.txt` разрешает каталог, Cloudflare не мешает,
   ClaudeBot в блок-листах нет. У обоих запрещён `/api/` — только HTML;
3. перейти на прямые фиды от агентств-партнёров из `data/channels.json`.

Закрыты наглухо: `chotot.com` / `nhatot.com` (блокируют ClaudeBot в robots.txt
и объявляют `ai-train=no`), `batdongsan.com.vn` (403 даже на robots.txt).
`alonhadat.com.vn` — самый большой объём, но в футере прямой запрет копирования
без письменного согласия.
