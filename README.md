# Art Estate — сайт недвижимости на Пхукете

Премиальный лендинг с кинематографичным скролл-облётом Пхукета (видео скрабится скроллом, Apple-style).

## Как запустить локально

```bash
cd "Art Estate"
python3 -m http.server 8123
```
Откройте в браузере: **http://localhost:8123**

> Важно: открывать именно через сервер (а не двойным кликом по `index.html`),
> иначе браузер может не отдать видео для покадровой перемотки.

## Структура

```
index.html              — разметка всех секций
css/styles.css          — стили (палитра «тропический премиум»)
js/script.js            — скролл-скраб видео, анимации, счётчики, рендер каталога
data/
  catalog.json          — данные каталога (создаёт парсер)
scraper/
  scrape_fazwaz.py      — парсер объектов с fazwaz.ru
  README.md             — инструкция по парсеру
assets/
  flythrough-long.mp4   — длинный облёт: остров → вилла → вход → интерьер (all-intra)
  flythrough-scrub.mp4  — короткий облёт (запасной)
  hero-phuket.jpg       — постер hero / фолбэк
  catalog/              — фотографии объектов (скачивает парсер)
  villa.jpg, apartment.jpg, penthouse.jpg — фолбэк-фото каталога
  pool.jpg              — фон блока «Об Алене»
```

## Видео-облёт (hero)

22-секундный кинематографичный облёт, который скрабится скроллом: камера летит
над Пхукетом → подлетает к вилле → входит в стеклянные двери → влетает в интерьер
с видом на океан. Закодирован all-intra (каждый кадр ключевой) для идеально
плавной перемотки. Поверх сменяются 3 текстовых слоя синхронно с актами.

Сгенерировано в Higgsfield (кадры — `nano_banana_pro`, видео — `seedance_2.0`
с переходами по start/end-кадрам) и склеено через `ffmpeg`.

## Каталог из fazwaz.ru

Каталог рендерится из `data/catalog.json`. Обновить реальными объектами:

```bash
python3 scraper/scrape_fazwaz.py --pages 1 --limit 12
```
Затем обновите страницу. Подробности и параметры — в `scraper/README.md`.
⚠️ См. правовое замечание там: фото/описания принадлежат fazwaz и их партнёрам.

## Функции каталога (как у fazwaz, в нашем дизайне)

- **Поиск и фильтры** над каталогом: текстовый поиск (название/район), тип,
  спальни, диапазон цены, сортировка (цена / площадь / $ за м²), счётчик
  результатов. Всё мгновенно, на стороне браузера — без бэкенда.
- **Сравнение**: кнопка «Сравнить» на карточке → плавающая панель (до 4 объектов)
  → модалка со сравнительной таблицей (цена, $/м², спальни, площадь, пляж,
  аренда, доходность).
- **Карточка объекта** (по клику): фото, характеристики, описание, кнопки
  WhatsApp/Telegram с подстановкой названия объекта, и два калькулятора:
  - **Кредитный** — стоимость, первоначальный взнос %, ставка %, срок →
    платёж/мес, сумма кредита, переплата (аннуитет).
  - **Доходности** — стоимость, аренда/мес, загрузка % → доход/год, доходность,
    окупаемость. Аренда подставляется из объявления либо оценивается (~6%).

Курс KZT→USD и допущения калькуляторов (ставка/срок/загрузка) — дефолтные,
правятся: курс в `scraper/scrape_fazwaz.py` (`RATES_TO_USD`), дефолты
калькуляторов — в `js/script.js` (значения `value=...` у инпутов).

## Функции «как у fazwaz» (вторая волна)

- **Поисковая панель** под героем: строка поиска + быстрые чипсы районов → ведёт в каталог.
- **Бейджи на карточках**: «X% доходность от аренды» (считается) и «−X%» скидка
  (по `firstPrice` из объявления, показывается зачёркнутая старая цена).
- **Избранное (♥)** на карточках — хранится в браузере (localStorage), фильтр
  «Избранное» в тулбаре.
- **Фильтр по району** и кнопка **«Показать ещё»** (пагинация по 9).
- **Секция «Районы Пхукета»** — карточки районов с числом объектов → клик фильтрует каталог.
- **Секция «Гибкие способы покупки»** — аренда с выкупом, рассрочка, поэтапная
  оплата + кнопка, открывающая калькуляторы.
- **Мини-карта (Leaflet + OpenStreetMap)** в карточке объекта по координатам из
  данных (`lat`/`lng`). Требует интернет для тайлов карты.

## Функции «как у fazwaz» (третья волна)

- **Боковое меню (drawer)** по кнопке ☰ — навигация, переключатель валюты,
  контакты, кнопки WhatsApp/Telegram, «Оставить заявку».
- **Переключатель валюты USD / ₽ / ฿** — мгновенно пересчитывает все цены
  (карточки, скидки, $/м², сравнение, срочная продажа, карта). Выбор сохраняется
  в браузере. Курсы — в `js/script.js`, объект `CURRENCIES` (правятся под актуальные).
  Калькуляторы в карточке считают в USD (помечено «$»).
- **Блок «Почему с нами»** с зацикленным видео-облётом и тремя преимуществами.
- **Секция «Срочная продажа»** — объекты со скидкой (старая/новая цена, «−X%»).
- **Секция «Объекты на карте»** — все объекты каталога маркерами на карте Пхукета
  (Leaflet + OpenStreetMap); клик по маркеру → цена и кнопка «Подробнее».

## Обновление каталога по расписанию

Ручной запуск:
```bash
bash scraper/update-catalog.sh           # 18 объектов, 1 страница
PAGES=2 LIMIT=30 bash scraper/update-catalog.sh
```
Автоматически (cron, ежедневно в 06:00):
```
crontab -e
0 6 * * * /bin/bash "<путь>/Art Estate/scraper/update-catalog.sh" >> /tmp/art-estate-catalog.log 2>&1
```
Подробности (launchd, /schedule) — в начале `scraper/update-catalog.sh`.
