# Парсер каталога — `scrape_fazwaz.py`

Обновляет каталог сайта Art Estate реальными объектами недвижимости с
**fazwaz.ru** (Пхукет): собирает данные карточек, скачивает фотографии и
формирует `data/catalog.json`, который сайт рендерит автоматически.

## ⚠️ Правовое замечание

fazwaz.ru — сторонний сайт. **Фотографии и описания принадлежат их
авторам/агентствам**, а Условия использования таких площадок, как правило,
запрещают автоматический сбор и перепубликацию контента (на фото также есть
их водяной знак). Используйте инструмент ответственно:

- как **источник рыночных данных** (цены, площади, локации) для аналитики;
- для объектов, на которые **у вас есть права** или договорённость с агентством;
- **не** выдавайте чужие листинги с чужими фото за свои.

Парсер уважает `robots.txt`: fazwaz запрещает `/api/` и `/graphql` — мы их
**не трогаем**, читаем только публичные HTML-страницы, с паузами между запросами.

## Требования

- Python 3.9+
- пакет `requests` (обычно уже установлен; иначе `pip3 install requests`)

bs4/Selenium/Playwright **не нужны** — данные берутся из встроенных в разметку
JSON-блоков карточек.

## Запуск

```bash
cd "Art Estate"

# базово: первая страница, 9 объектов, крупные фото с detail-страниц
python3 scraper/scrape_fazwaz.py --pages 1 --limit 9

# больше объектов с нескольких страниц
python3 scraper/scrape_fazwaz.py --pages 3 --limit 18

# только виллы
python3 scraper/scrape_fazwaz.py --category "/вилла-продажа/таиланд/пхукет" --pages 2 --limit 12

# быстро, без захода на detail-страницы (фото мельче, 268×200)
python3 scraper/scrape_fazwaz.py --no-hires --limit 12
```

После запуска просто обновите страницу сайта — каталог подтянет новые данные.

## Параметры

| Флаг | По умолчанию | Описание |
|------|--------------|----------|
| `--category` | `/недвижимость-продажа/таиланд/пхукет` | путь категории на fazwaz.ru |
| `--pages` | `1` | сколько страниц листинга обойти |
| `--limit` | `9` | максимум объектов в каталоге |
| `--delay` | `1.2` | пауза между запросами, сек (вежливость) |
| `--no-hires` | выкл. | не заходить на detail-страницы (быстрее, фото мельче) |
| `--allow-dup-titles` | выкл. | не схлопывать объекты одного ЖК |
| `--out-json` | `data/catalog.json` | куда писать каталог |
| `--img-dir` | `assets/catalog` | куда складывать фото |

## Категории fazwaz (примеры `--category`)

```
/недвижимость-продажа/таиланд/пхукет        — вся недвижимость
/вилла-продажа/таиланд/пхукет               — виллы
/квартира-продажа/таиланд/пхукет            — квартиры
/кондо-продажа/таиланд/пхукет               — кондо
/дом-продажа/таиланд/пхукет                 — дома
/недвижимость-продажа/таиланд/пхукет/камала — конкретный район
```

## Цены и валюта

fazwaz.ru отдаёт цены в **KZT**. Парсер конвертирует их в USD по курсу из
константы `RATES_TO_USD` в начале `scrape_fazwaz.py` (по умолчанию ~485 KZT/$).
**Обновляйте курс** под актуальный или поменяйте логику отображения. В
`catalog.json` сохраняются и `priceUSD`, и исходная `priceOriginal`.

нет (или открываете не через сервер) — показываются 3 демо-объекта из фолбэка.

## Если разметка fazwaz изменится

Данные берутся из блока `bridgeSearchMouseOver` в HTML карточки (регэксп
`CARD_RE`) и из крупных изображений на detail-странице (`DETAIL_IMG_SIZES`).
Если сайт-источник поменяет вёрстку — поправьте эти места в `scrape_fazwaz.py`.
