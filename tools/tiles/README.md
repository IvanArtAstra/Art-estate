# Своя подложка карт

Карты на сайте рисуются нашими тайлами с Cloudflare R2, а не чужим
сервером. Причина простая: в правилах публичного тайл-сервера
OpenStreetMap прямо написано, что коммерческим сайтам доступ могут
отозвать без предупреждения. Карта на странице объекта — часть
продажи, и зависеть от чужого доброго отношения она не должна.

Побочные выгоды оказались не меньше самой независимости:

- карта нарисована в палитре сайта, а не в чужой серо-голубой;
- подписи по-русски даже в Таиланде и Вьетнаме — векторные тайлы
  несут все языки сразу, язык выбирается при отрисовке;
- тайлы кэшируются и не стоят ничего: R2 не берёт плату за исходящий
  трафик, а 10 ГБ хранения бесплатны. Наш файл — около 220 МБ.

## Что внутри файла

Один `.pmtiles` — это весь архив тайлов в одном файле, который браузер
читает кусками по HTTP Range. Целиком он никогда не скачивается.

Собираем из четырёх непересекающихся слоёв, чтобы не тащить планету
(139 ГБ) ради четырёх побережий:

| Слой | Зумы | Зачем |
|---|---|---|
| Весь мир | 0–6 | Обзорная карта без дыр |
| Таиланд и Вьетнам | 7–10 | Страна целиком, до городов |
| Турция | 7–10 | Аланья впереди, подложка готова |
| Наши районы | 11–15 | Пхукет, Дананг, Нячанг, побережье Антальи — до домов |

Дальше 15-го зума вектор растягивается: это не каша из пикселей, а та
же чёткая графика крупнее, поэтому карта объекта работает до 18-го.

Границы районов — в `regions.geojson`. Появится новая страна — добавьте
прямоугольник туда и пересоберите.

## Пересобрать

Сборка Protomaps обновляется ежедневно; раз в несколько месяцев имеет
смысл обновиться, чтобы на карте появились новые дома и дороги.

```bash
brew install pmtiles
bash tools/tiles/build.sh            # ~10 минут, нужен интернет
BUILD=20261104 bash tools/tiles/build.sh   # конкретная сборка
```

Свежий номер сборки — на https://maps.protomaps.com/builds

## Выложить

Файл меньше 300 МБ — ровно затем, чтобы его можно было загрузить
перетаскиванием в веб-панели R2 и не ставить rclone.

1. Cloudflare → R2 → **Enable R2** (одноразово, просят принять условия).
2. Создать бакет `estateart-tiles`.
3. Перетащить `tools/tiles/estateart-basemap.pmtiles` в бакет.
4. Settings → **Public access** → включить `r2.dev` домен.
5. Settings → **CORS policy** → разрешить наш сайт:

```json
[{ "AllowedOrigins": ["https://estateart.homes"],
   "AllowedMethods": ["GET", "HEAD"],
   "AllowedHeaders": ["range"],
   "ExposeHeaders": ["etag", "content-length", "content-range"],
   "MaxAgeSeconds": 86400 }]
```

6. Скопировать выданный адрес и вписать его в `js/basemap.js` в
   переменную `TILES`. Пустая переменная — карта работает на растровом
   OpenStreetMap, как раньше.

### Про адрес

`pub-….r2.dev` Cloudflare отдаёт с ограничением скорости и называет
непроизводственным. Это терпимо на нашем трафике, но правильный адрес —
свой поддомен `tiles.estateart.homes`. Для него зону estateart.homes
нужно перенести на Cloudflare: сейчас DNS живёт на Dynadot. Перенос
заодно позволил бы увести с `workers.dev` и чат. Решение не техническое,
а ваше — пока работаем на `r2.dev`.
