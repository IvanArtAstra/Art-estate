# Чат на сайте ↔ Telegram

**Бот проекта: [@EstateArtHomesBot](https://t.me/EstateArtHomesBot)**

## Запуск за три команды

```bash
npm install -g wrangler && wrangler login
bash bot/setup.sh                 # создаст bot/.secrets.env, если его нет
# заполните файл, затем:
bash bot/setup.sh
```

Значения живут в `bot/.secrets.env` — он закрыт в `.gitignore` и в репозиторий
не попадёт. Скрипт создаёт хранилище, заливает секреты в Cloudflare, выкатывает
воркер, ставит вебхук, прописывает адрес воркера в `index.html` и проверяет
`/api/health`. В конце предлагает затереть файл: значения уже в Cloudflare,
на диске им делать нечего.

Вспомогательное:

| Команда | Зачем |
|---|---|
| `bash bot/chat-id.sh` | Показать `chat_id` личек и групп, где бот уже был |
| `bash bot/push-secrets.sh` | То же, что `setup.sh`, без проверок — перезалить и передеплоить |
| `bash bot/push-secrets.sh --unhook` | Снять вебхук на минуту, чтобы заработал `getUpdates` |

Ручная настройка по шагам — дальше, она пригодится, если что-то пойдёт не так.

> **Токен в репозиторий не кладут. Никогда.** Репозиторий публичный: токен,
> попавший в любой файл здесь, в историю git или в `wrangler.toml`, уводят в
> первые же часы. Токен живёт только в секретах Cloudflare. Если токен где-то
> засветился — в переписке, в скриншоте, в логе — отзовите его в @BotFather
> командой `/revoke` и выпустите новый, это бесплатно и занимает полминуты.

Посетитель пишет в виджет на сайте → сообщение приходит вам в Telegram от бота →
вы отвечаете **реплаем** на это сообщение → ответ появляется у посетителя на сайте.

Токен бота живёт в секретах Cloudflare и в браузер не попадает никогда. Класть
токен в JS на публичной странице нельзя: его забирают в первые же часы и угоняют бота.

```
посетитель ──POST /api/send──▶ Worker ──sendMessage──▶ Telegram (вы)
посетитель ◀──GET /api/poll── Worker ◀──webhook────── ваш реплай
```

## Что понадобится

- бесплатный аккаунт Cloudflare;
- бот [@EstateArtHomesBot](https://t.me/EstateArtHomesBot) — уже создан; токен
  берётся в [@BotFather](https://t.me/BotFather) командой `/token`;
- 10 минут.

## Настройка

**1. Поставьте wrangler и войдите**

```bash
npm install -g wrangler
wrangler login
```

**2. Создайте хранилище переписки**

```bash
cd bot
wrangler kv namespace create CHAT
```

Команда выдаст `id = "..."` — впишите его в `wrangler.toml` вместо
`ЗАМЕНИТЕ_НА_ID_ИЗ_KV_NAMESPACE_CREATE`.

**3. Положите секреты**

```bash
wrangler secret put BOT_TOKEN        # токен от @BotFather
wrangler secret put WEBHOOK_SECRET   # любая случайная строка, например: openssl rand -hex 16
```

`AGENT_CHAT_ID` — chat_id получателя заявок. Узнать так:
напишите своему боту `/start`, потом откройте в браузере
`https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates` и возьмите `message.chat.id`.

```bash
wrangler secret put AGENT_CHAT_ID
```

### Заявки в группу, а не в личку

`AGENT_CHAT_ID` принимает id группы — тогда заявки видит вся команда, и любой
отвечает реплаем. Два условия:

- **бот должен быть администратором группы.** Обычный участник по умолчанию не
  видит чужих сообщений (privacy mode), и реплай до него не дойдёт;
- **id группы отрицательный**, вида `-1001234567890`. Минус — часть id, без него
  Telegram ответит «chat not found».

Узнать id: напишите что-нибудь в группу и выполните `bash bot/chat-id.sh`.

### Несколько дежурных менеджеров

В `AGENT_CHAT_ID` можно положить несколько id через запятую:

```
123456789,987654321,555000111
```

Тогда новые диалоги распределяются по кругу: первая заявка первому, вторая
второму и так далее. Дальше переписка держится за назначенным — клиент не
объясняет одно и то же разным людям.

Остальные дежурные получают короткое уведомление о новой заявке. Если назначенный
не на связи, любой коллега отвечает реплаем у себя и диалог переходит к нему.

Команда `/duty` в боте показывает, сколько дежурных в ротации и кому уйдёт
следующая заявка.

**4. Проверьте разрешённые домены**

В `wrangler.toml` в `ALLOWED_ORIGINS` перечислены адреса, с которых виджету можно
обращаться. По умолчанию это боевой сайт и локальный сервер. Свой домен добавьте
туда же через запятую.

**5. Выкатите**

```bash
wrangler deploy
```

Получите адрес вида `https://estate-art-chat.<ваш-субдомен>.workers.dev`.

**6. Подпишите бота на вебхук**

```bash
curl -X POST "https://api.telegram.org/bot<ВАШ_ТОКЕН>/setWebhook" \
  -H "content-type: application/json" \
  -d '{"url":"https://estate-art-chat.<ваш-субдомен>.workers.dev/api/telegram","secret_token":"<ТОТ_ЖЕ_WEBHOOK_SECRET>","allowed_updates":["message"]}'
```

Ответ должен быть `{"ok":true,...}`.

**7. Пропишите адрес воркера на сайте**

В `index.html` найдите строку с `data-chat-endpoint` и подставьте свой адрес:

```html
<body data-chat-endpoint="https://estate-art-chat.<ваш-субдомен>.workers.dev">
```

Пока адрес не задан, виджет просто не показывается — сайт работает как раньше.

## Первичный менеджер на Claude

Первым в диалоге отвечает менеджер на Claude — и в чате на сайте, и в самом боте.
Он доводит разговор до контакта и передаёт живому агенту готовой карточкой:
имя, контакт, что ищет, город, бюджет, сроки, заметки.

Включается одним секретом:

```bash
wrangler secret put ANTHROPIC_API_KEY
```

Без ключа всё работает по-старому: сообщение уходит дежурному напрямую. Так же
воркер ведёт себя, если запрос к Anthropic упал — заявку нельзя терять из-за
того, что сломался помощник.

**Ключ живёт только в секретах Cloudflare.** В клиентский JS его класть нельзя
ни при каких условиях: сайт статический и лежит в публичном репозитории, ключ
утечёт за часы, а счёт придёт владельцу. Поэтому виджет и бот ходят в воркер,
а к Anthropic ходит воркер.

### Что он говорит и чего не говорит

| | |
|---|---|
| **Цены** | Только диапазоны по району или городу, через инструмент `price_range`. Цену конкретного объекта не называет никогда: каталог — снимок на дату обновления, объект мог уйти или подорожать, и названная цифра стала бы обещанием, которое некому выполнить. |
| **Право и налоги** | Отвечает своими словами — freehold, квота, leasehold, сборы при покупке — и каждый раз оговаривает, что это ориентир, а не юридическая консультация. |
| **Передача человеку** | Как только есть имя и контакт, вызывает `save_lead` и замолкает. Дальше говорит агент. |
| **Чего не делает** | Не обещает доходность и сроки, не выдумывает комплексы и скидки, не торгуется. |

Ответ дежурного реплаем снимает помощника с диалога: два голоса в одном чате
клиент читает как неразбериху, а не как заботу. Потолок — 12 реплик на сессию,
дальше разговор уходит человеку в любом случае.

### Таблица диапазонов

`data/price-ranges.json` собирается из каталога:

```bash
python3 tools/price_ranges.py
```

Район попадает в таблицу, только если в нём хотя бы три объекта: по двум
«диапазон» — это два случайных числа. Воркер тянет таблицу с сайта и держит
в KV шесть часов.

Запускать вручную обычно не нужно: пересборка встроена в `update-catalog.sh`,
в кнопку «Спарсить и обновить» в админке и в `switch_domain.py`. Отдельный
ритуал здесь был бы ошибкой — забытый запуск означает, что менеджер называет
клиентам вилки по вчерашнему каталогу.

Состав каталога кладётся прямо в системный промпт, поэтому модель с первого
раза спрашивает существующий район, а не перебирает варианты по кругу.
Названия районов в каталоге живут в двух алфавитах («Чернг Талай» рядом с
«An Hai Bac»), поэтому сверка нестрогая — без регистра, пробелов и дефисов.

## Оформление бота

Почти всё ставится одной командой:

```bash
bash bot/brand.sh
```

Скрипт задаёт через Bot API имя, описание на пустом экране, строку «о боте»,
команды и кнопку меню — по-русски и по-английски, и в конце показывает, что
получилось. Запускать можно сколько угодно раз.

**Аватар — единственное, чего Bot API не умеет.** Файл готов:
`bot/avatar.png`, 512×512, исходник `assets/bot-avatar.svg`. Пришлите его в
[@BotFather](https://t.me/BotFather) командой `/setuserpic`.

Рамка на аватаре круглая не по вкусу: Telegram обрезает аватар в круг, и углы
квадратной рамки ушли бы, оставив четыре обрубка по сторонам.

Таблица ниже — что именно получает клиент; она же пригодится, если понадобится
поправить тексты руками.

| Команда BotFather | Что вписать |
|---|---|
| `/setname` | `Estate Art — недвижимость Пхукет и Вьетнам` |
| `/setdescription` | Текст на пустом экране до старта диалога (см. ниже) |
| `/setabouttext` | Короткая строка в профиле (см. ниже) |
| `/setuserpic` | `assets/favicon.svg`, перегнанный в PNG 512×512 на тёмном фоне `#082825` |
| `/setcommands` | Список команд (см. ниже) |
| `/setmenubutton` | Кнопка «Открыть каталог» → `https://estateart.homes/` |

**Описание** (`/setdescription`, до 512 знаков):

```
Виллы и квартиры на Пхукете, в Дананге и Нячанге.

Подбираем объект под задачу — жить, сдавать или держать, — проверяем документы
и ведём сделку от первого показа до ключей. Работаем удалённо: онлайн-показы,
видео-туры, сопровождение переводов.

Напишите, что ищете, — ответит живой человек.
```

**О боте** (`/setabouttext`, до 120 знаков):

```
Недвижимость на Пхукете и во Вьетнаме. Подбор, проверка документов, сделка под ключ.
```

**Команды** (`/setcommands`):

```
start - Начать подбор
catalog - Каталог объектов на сайте
contact - Связаться с агентом
duty - Кто сегодня на связи (для своих)
```

`/duty` оставлен в списке осознанно: команда отвечает только дежурным
менеджерам, посторонним — отказ.

## Проверка

1. `curl https://estate-art-chat.<...>.workers.dev/api/health` → `{"ok":true}`
2. Откройте сайт, нажмите кнопку чата, напишите что-нибудь.
3. Сообщение придёт вам в Telegram с пометкой `#идентификатор`.
4. Ответьте на него **реплаем**. Бот поставит 👌, ответ появится на сайте за пару секунд.

## Как это себя ведёт

- **Реплай обязателен.** Обычное сообщение в чат с ботом никуда не уйдёт — бот
  не знает, кому адресовать, и прямо об этом скажет.
- **Переписка живёт 14 дней**, потом удаляется из хранилища автоматически.
- **Ограничение**: 20 сообщений в минуту с одного IP, 2000 символов на сообщение,
  200 сообщений на диалог.
- **Задержка ответа** — до 4 секунд: виджет опрашивает воркер, а не держит
  постоянное соединение. Плюс у KV возможна задержка в пару секунд на запись,
  это особенность хранилища.
- **Лимиты бесплатного тарифа Cloudflare**: 100 000 запросов в день. Один диалог
  это примерно 30–60 запросов, то есть запас огромный.

## Приватность

Сообщения посетителей лежат в KV Cloudflare 14 дней. В форме чата стоит согласие
на обработку персональных данных со ссылкой на политику — не убирайте его.
Если будете хранить переписку дольше или переносить в CRM, это нужно отразить
в политике конфиденциальности.

## Если что-то не работает

| Симптом | Причина |
|---|---|
| Виджета нет на сайте | не задан `data-chat-endpoint` в `index.html` |
| В консоли CORS-ошибка | домен сайта не внесён в `ALLOWED_ORIGINS` |
| Сообщения не доходят в Telegram | неверный `AGENT_CHAT_ID`, либо вы не писали боту `/start` |
| Ответы не доходят на сайт | вебхук не установлен или `WEBHOOK_SECRET` не совпадает — проверьте `getWebhookInfo` |
| `{"ok":false,"error_code":409}` | вебхук конфликтует с запущенным где-то `getUpdates`-поллингом |

Логи воркера в реальном времени: `wrangler tail`.
