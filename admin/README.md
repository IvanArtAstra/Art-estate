# Админ-панель Estate Art (локальная)

Панель оператора для управления каталогом, парсинга и публикации.
Работает **на вашем компьютере** — GitHub Pages (статика) не может выполнять
вход, серверное редактирование и Python-парсер.

## Запуск

```bash
cd "Art Estate"
python3 admin/server.py
```
Откройте **http://127.0.0.1:8787/admin/**

При первом запуске создаётся аккаунт `admin` и **пароль печатается в консоль** —
сохраните его. Сменить логин/пароль:

```bash
python3 admin/server.py --set-user myname --set-pass 'мой-пароль'
```
Можно также задать через переменные окружения `ADMIN_USER` / `ADMIN_PASS`.

## Что умеет

- **Вход** по логину/паролю (сессия в cookie, сервер слушает только 127.0.0.1).
- **Статистика**: число объектов, средняя цена, портфель, доходность, скидки,
  галерея/гео, разбивка по типам.
- **«Спарсить и обновить»** — запускает `scrape_fazwaz.py` → `enrich_gallery.py`
  → `build_pages.py` с прогрессом в реальном времени. Перезаписывает каталог.
- **Редактор каталога** — правка названия, цены, типа, спален, площади, описания,
  скрытие (флаг `hidden` — объект исчезает с сайта), удаление, изменение порядка.
  Сохраняется в `data/catalog.json`.
- **«Опубликовать»** — `git add/commit/push`; публичный сайт обновится за ~1 минуту.

## Поток работы

1. Запустить панель → войти.
2. Нажать «Спарсить и обновить» (или вручную поправить объекты в редакторе).
3. Проверить статистику.
4. Нажать «Опубликовать» → изменения уезжают в GitHub → сайт обновляется.

## Безопасность

- `admin/admin_config.json` (хэш пароля) **в .gitignore** — не попадает в публичный репозиторий.
- Панель привязана к `127.0.0.1` и не доступна из сети. Не пробрасывайте порт наружу
  без HTTPS и усиленной аутентификации.

## Если нужна онлайн-админка

Понадобится хостинг с бэкендом (Netlify/Vercel Functions, Render, свой VPS) —
тогда панель и API будут доступны по адресу в интернете. Текущее решение
сознательно локальное: бесплатно, безопасно и без смены хостинга сайта.
